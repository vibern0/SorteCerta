# Saved brand comparisons

29 September 2026. Design explorations for existing USDC holders in Nigeria and Kenya. Emotional emphasis: prize excitement.

**Chosen: Direction 02 — playful and expressive.** The founder selected this concept on 29 September 2026. See the [brand decision](../../BRAND_DIRECTION.md) for the enduring reference and scope. “Direction 02” refers to the playful concept, not file `02-ink-citron.html`.

## Original direction

The first concept uses bold typography, restrained decoration, and a shared palette across marketing and the app.

- [Cobalt and coral](01-cobalt-coral.html)
- [Ink and citron](02-ink-citron.html)
- [Plum and peach](03-plum-peach.html)

The original editable fragment is preserved in [sources/original-directions.html](sources/original-directions.html). These alternatives remain archived for comparison; they are not the chosen direction.

## Chosen direction: playful and expressive

The new concept uses rounded Fredoka display typography, DM Sans body text, angled stickers, shaped color blocks, solid button shadows, and brighter secondary colors. It retains the main headline and eligibility explanation to make visual personality easier to compare.

- [Playful cobalt, peach, and citron](04-playful-cobalt.html)
- [Playful berry, pink, and butter](05-playful-berry.html)
- [Playful teal, apricot, and sky](06-playful-teal.html)

Editable fragment: [sources/playful-directions.html](sources/playful-directions.html).

## Viewing and scope

Open the exported HTML files in a browser. They preserve each palette as a separate default snapshot. Design controls in the conversation allow switching palettes and example app states; those host controls are not required to view the exported versions. The playful version loads fonts from Google Fonts and falls back to system fonts when unavailable. Both versions use the visualization renderer's CDN resources, so these are not fully offline archives.

The depicted app states are illustrative, with no wallet connection or financial operations. No production app or landing styles were changed. The playful creative direction is approved. The cobalt version is the saved default reference; a preference between the playful palette variants was not separately recorded. Kettigo remains the working name, and production specifications still need to be formalized.
